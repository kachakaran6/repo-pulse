# UI v2: design direction

Builds on 03-DESIGN-SYSTEM.md. Same quiet ledger feel, now with real product screens and one new idea: **triage**.

## Big idea
Other trackers show charts. RepoPulse asks one question per repo: **Keep going, Pause, or Retire?** The interface is built around making that decision fast.

## Screens
1. **Overview.** Top line is a plain sentence from rules, not AI: "You committed to 3 repos this week. 2 went cold." Below: grouped repos with strips. Counts in tabular numbers.
2. **Triage.** One repo at a time, big and calm: name, last commit date, 90-day strip, label. Three buttons: Keep going (optional goal date), Pause (pick a return date), Retire (moves to Archive). Keys: K, P, R. Progress as "4 of 11 decided".
3. **Archive.** Retired repos in a quiet list, with "Bring back" per row.
4. **Repo detail.** 90-day strip with week ticks, commit counts, label, goal, note, decision history.
5. **Settings.** Thresholds, theme, connected GitHub installation, export data, delete account.
6. **Sign in / onboarding.** Three steps: sign in, choose repos on GitHub, first sync with true progress ("Read 14 of 31 repos").

## Shell
Top bar, not a generic sidebar: wordmark left, tabs (Overview, Triage, Archive, Settings), avatar menu right. Content max width 1040px, left aligned.

## Type
Schibsted Grotesk only. Sizes 13 / 15 / 18 / 22 / 28 / 40. `font-variant-numeric: tabular-nums` on counts and dates. Triage repo name at 40px.

## Components
Button (primary ink, secondary outline, quiet text), tab, repo row, strip, label chip, decision button group, date picker (native input), toast, dialog (confirm delete only), skeleton row, empty state.

## States (design all of them)
- Loading: skeleton rows, never a blank page
- Empty: tells what to do next ("Install the GitHub App to choose repos")
- Error: what failed + one action ("GitHub is rate limiting us. Sync resumes at 14:20.")
- Offline / session expired: calm banner with "Sign in again"
- Success: quiet toast, no confetti

## Motion
150ms ease on hover, focus, tab change and row removal after a decision. Nothing animates on page load. Reduced motion: none.

## Banned (AI-look checklist, extended)
Gradients, glow, glass, emoji, "Welcome back 👋", stock isometric art, identical card grids, left-border cards, purple/blue gradient buttons, floating blobs, sparkle icons, fake testimonials, fake charts, ALL-CAPS tracked labels, middle-dot meta strings, "Supercharge / seamless / unlock".

## Accessibility floor
Keyboard reachable everywhere, visible 2px focus ring, 44px touch targets, labels on all inputs, status never shown by color alone (always the word too), works at 375px.
